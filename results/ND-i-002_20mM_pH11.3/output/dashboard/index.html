Multiscale Physical Scattering Formalism

The total experimental scattering intensity \(I(q)\) is modelled across the entire momentum transfer range \(q \in [0.002, 2.5]\text{ nm}^{-1}\) as the coherent linear superposition of four structural contributions:

\[ I_{\mathrm{tot}}(q) = I_{\mathrm{prim}}(q) + I_{\mathrm{large}}(q) + I_{\mathrm{fluc}}(q) + I_{\mathrm{bkg}} \]

1. Primary Fractal Network

Polydisperse spherical building blocks following a log-normal size distribution \(n(R)\) with inter-particle Teixeira mass fractal structure factor \(S(q)\):

\[ I_{\mathrm{prim}}(q) = (\Delta\rho)^2 \int_0^\infty n(R) V^2(R) P(q, R) S(q, R, D_f, \xi) \, dR \] \[ S(q, R, D_f, \xi) = 1 + \frac{D_f \Gamma(D_f - 1)}{(q R)^{D_f}} \frac{\sin[(D_f - 1) \arctan(q \xi)]}{\left(1 + (q \xi)^{-2}\right)^{(D_f - 1)/2}} \]

2. Secondary Macroscopic Droplets

Dilute secondary dense liquid phase droplets with log-normal polydispersity and constant relative dispersion \(\sigma_{\mathrm{large}} / \langle R_{\mathrm{large}} \rangle = \text{const}\):

\[ I_{\mathrm{large}}(q) = (\Delta\rho)^2 \int_0^\infty n_{\mathrm{large}}(R) V^2(R) P(q, R) \, dR \]

3. Viscoelastic Network Concentration Fluctuations

Dynamic viscoelastic network fluctuations (Fisher-Burford / Tanaka formulation with \(\mu_{\mathrm{fluc}} = 4.0\)) explaining the high-\(q\) excess:

\[ I_{\mathrm{fluc}}(q) = \frac{A_{\mathrm{fluc}}}{\left[1 + \frac{2}{3 \mu_{\mathrm{fluc}}} (q \xi_{\mathrm{fluc}})^2\right]^{\mu_{\mathrm{fluc}} / 2}} \]
